## 下一步需要用户操作

1. 核对体脂秤背面型号是否为 XMTZC05HM。XMTZC04HM 和其他型号暂不支持。
2. 在真实看板中填写个人档案，并将秤放在服务器的蓝牙范围内。
3. 停止当前服务，运行 `scripts/start-local.sh --connect`；如果 macOS 请求蓝牙权限，由用户允许。
4. 赤脚站上秤，等待体重和身体成分测量完成，再核对接收与保存结果。

上游正式支持 Linux + BlueZ。当前 Mac 的网页服务已验证，真实蓝牙接收尚未验证。Telegram、webhook、真实 AI 调用、手机安装和离线缓存未配置或未实测，相关说明与提示已经汉化。
